# 🛍️ PrimeEdge

### A Modern E-Commerce Web Application

PrimeEdge is a responsive e-commerce web application built with React.js, focused on providing a smooth and user-friendly shopping experience.

---

## ✨ Key Features

- 🛍️ Dynamic product listing
- 🔍 Product search
- 🎯 Product filtering
- ↕️ Product sorting
- 📄 Pagination
- 🔄 State management with Redux Toolkit
- 🌐 API integration
- 📱 Responsive user interface

---

## 🛠️ Tech Stack

### 🎨 Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- JavaScript
- HTML5
- CSS3

### 🔗 APIs & Tools
- REST APIs
- Git & GitHub

---

## 📌 Project Overview

PrimeEdge demonstrates a modern e-commerce interface with dynamic product handling and efficient state management.

The project focuses on building a responsive frontend with features such as **search, filtering, sorting, and pagination**, while using **Redux Toolkit** for state management and API integration for dynamic product data.
